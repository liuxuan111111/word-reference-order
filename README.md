# Word 参考文献顺序梳理 · word-reference-order

> 按正文首次引用顺序整理论文参考文献角标的辅助方案。

## 问题

论文正文增删段落后，参考文献角标序号与正文首次引用顺序不一致，手动逐个核对、重排序号工作量大且极易出错。

## 解决方案

用 Excel 表格（`角标.xlsx`）记录并梳理参考文献角标与正文引用位置的对应关系，配合 Word VBA 宏按首次引用位置提取页码、章节号，统一重新排序。

## 结果

参考文献角标按正文首次引用顺序正确排列，序号错乱问题一次性解决，整理过程可追溯、可复用。

## 文件清单

- `角标.xlsx` — 参考文献角标顺序梳理表

## 使用方式

在表格中登记正文引用位置与文献对应关系，据此重排角标；配合 `word-vba-macros` 中的「按顺序提取角标页面章节号」宏使用。
